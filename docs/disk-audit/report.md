# 디스크 조사·정리·검증 결과

측정일: 2026-09-15 (Asia/Seoul). 프로젝트: Mk.03-PirateSimulator.

## 플랫폼과 기존 동작

- README, package.json, Svelte/Vite/Playwright 설정, `.github/workflows/ci.yml`, 에셋 생성 도구와 기존 기술 문서를 확인했다. 루트/상위 경로/프로젝트 안에서 기존 AGENTS.md는 발견되지 않아 루트에 새 규칙을 추가했다.
- Phaser 3.90.0, SvelteKit 2.70.2, Svelte 5.56.8, Vite 8.2.0, adapter-static 3.0.10, Node 22.18.0 기반 **브라우저 게임**이다. Chromium/Firefox/WebKit 및 Pixel 7/iPhone 14 브라우저 테스트가 있다. 네이티브 PC·모바일·콘솔 패키징 설정은 없다.
- 기존 `npm run build`는 `vite build`를 직접 호출했다. SvelteKit이 `.svelte-kit/output`에 클라이언트·서버 중간 파일을 쓰고, adapter-static이 `build/`를 지운 다음 다시 복사했다(설치된 adapter-static `index.js`의 `builder.rimraf`/`writeClient` 확인). 실패 때 이전 정상본을 보장하지 못하는 순서였다.
- Playwright의 webServer도 `npm run build && npm run preview`를 호출한다. 날짜별 패키지 보관이나 압축 해제 반복 스크립트는 없다. 큰 원인은 의존성 및 원본 에셋의 **중간/최종 결과물 복사**이고, 개발 캐시 안에는 동일 내용의 ` 2` 사본도 있었다. 파일명만으로 지우지 않고 SHA-256 및 Vite 메타데이터의 원본 의존성 경로를 대조했다.
- CI는 workflow_dispatch 기반 품질 검사이며 배포 단계와 Git 태그는 없었다. 문서에 실제 출시 이후 운영 과제가 남아 있지만, 출시하지 않았다고 단정할 증거는 아니다. 기존 `build/`의 필요성이 불명확하므로 자동 삭제하지 않았다.

- 정리 직후 중요 원본·기존 패키지·검증 자료 **346개 전부** 해시 일치.
- 작업 완료 검증: 원본 코드/에셋, lockfile, 기존 패키지, 기존 검증 기록 등 **339개 변경 없음**. 자동화에 필요한 설정·README 7개는 의도적으로 수정했다. 원본 해시·검증 목록·변경 설정 목록과 기존 패키지의 새 위치는 [protected-sha256.json](protected-sha256.json)에 기록했다.
- 기존 `build/` 105개 파일은 `.build-artifacts/preserved/<ID>/package`에 내용 변경 없이 보존했다. 최신 `build` 링크는 새 개발 패키지를 가리킨다. 기존 검증 이미지/보고서는 덮어쓰지 않았다.
- `.git`, 필수 의존성, 에셋 생성 도구, 원본 에셋과 게임 기능은 정리 대상으로 삼지 않았다. 공유 npm/브라우저 캐시를 삭제하지 않았다. 서명 키·인증 파일·출시 패키지/심볼로 확인된 별도 파일은 발견되지 않았다. 브라우저 사용자 저장소(IndexedDB/localStorage)는 접근하지 않았으며 검증은 임시 브라우저 프로필에서 수행했다.

## 자동화

`npm run build`와 CI/Playwright 빌드가 같은 Python 수명주기를 사용한다. 작업별 공간과 소유 표식, 영구 POSIX 잠금과 자식 상속, 작업 그룹 확인으로 성공·실패·취소·일반 중단 및 강제 종료 이후 회수를 처리한다. 다른 작업의 잠금/파일과 임의 경로를 삭제하지 않는다. 출처 불명 경로와 정리 실패는 경고·경로·실패 종료 코드로 남긴다.

후보 패키지 검증 뒤에만 게시하고 기존 패키지는 유지한다. 최초 기존 디렉토리→링크 전환은 복구 저널을 사용하며, 그 이후 포인터 교체는 원자적이다. 개발 패키지 2회, 로그 10회×1MiB; 출시·기존 롤백 가능 자료·심볼은 별도 무기한 보존한다. CI 로그/브라우저 보고서의 14일 정책도 적용한다. 원격 배포를 새로 수행하지 않았다.

## 전후 실측

최종 수치는 [after.json](after.json)에 기록한다. 최초 전체 할당 용량은 **607.73MiB**, 최초 논리 파일 크기는 **576.79MiB**였다. 정리 직후 파일시스템 여유 공간 관측 증가는 **73.77MiB**였으며, 삭제 파일의 할당량 감소 **95.25MiB**와 다르다.

최종 프로젝트에는 기존 보존 패키지 외에 검증한 새 개발 패키지 약 58.75MiB, 재생성한 테스트 캐시 약 6MiB와 감사 기록이 포함된다. 따라서 최종 순감소량은 최초 삭제량보다 작다. 최종 파일시스템 여유 공간 차이에는 동시에 실행된 다른 프로세스의 쓰기/정리가 섞이며 APFS 공유 블록도 영향을 줄 수 있다. **관측한 여유 공간 증가를 이 작업만의 정확한 물리 해제량으로 해석하지 않는다.** Git 저장소는 정리하지 않았고 세션 중 외부에서 커밋이 추가된 것도 확인했다.
